# 心肺复苏

课程时间：2026.8.21 16:45~17:45

主讲：余涛

## 心搏骤停的定义与流行病学

指心脏泵血功能突然终止，全身血液循环中断，迅速出现意识丧失、大动脉搏动消失、呼吸停止或濒死喘息

一些名词解释

```
心源性猝死SCD：心脏原因所致，急性症状起病1小时内发生的死亡，是心搏骤停抢救失败的结局。

BLS基础生命支持：现场徒手抢救，胸外按压、开放气道、人工呼吸、AED除颤，不需要高级设备。

ACLS高级心血管生命支持：专业人员实施，建立高级气道、给药、电除颤、循环支持。

ROSC自主循环恢复：恢复可触及的大动脉搏动，恢复有效心输出量，复苏成功标志。
```

## BLS基础生命支持：生存链、C‑A‑B流程

成人院外生存链：

识别呼救→旁观者CPR→早期AED除颤→高级急救→ROSC后综合救治→康复

> 临床原则：即使发生肋骨骨折，也不能停止按压，生存获益远大于损伤。

### 胸部按压 C

100~120次每分钟

成人深度：5‑6cm，禁止＞6cm

### 开放气道 A

仰头抬颏法：一手压额头，另一手上抬下颌，打开气道；怀疑颈椎损伤用托颌法

### 人工呼吸 B

口对面膜、口对面罩人工呼吸（防止传染性疾病）

单纯胸外按压的心肺复苏

## 除颤

原理

心脏的各个地方肌肉运动不同步，电击先让心肌全部暂停，再恢复正常跳动

除颤仪

1. 除颤器
2. 自动体外除颤器（AED）

使用方法：打开电源、贴电极片（右胸上方、左胸侧面肋骨处）、所有人离开，机器分析心律、提示除颤时再次确认离开，按下放电；

放电后继续心肺复苏

## 终止心肺复苏指征

满足其一即可终止：

1. 自主循环恢复ROSC：恢复自主呼吸、可触及大动脉搏动，生命体征稳定
2. 现场专业人员确认生物学死亡：尸僵、尸斑、严重躯体毁损，瞳孔散大固定无反射
3. 规范高质量 CPR持续≥30min，始终无ROSC，排除低温、中毒、电解质紊乱等可逆因素
