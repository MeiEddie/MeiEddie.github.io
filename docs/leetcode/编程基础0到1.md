### 1768. 交替合并字符串

给你两个字符串word1和word2。请你从word1开始，通过交替添加字母来合并字符串。如果一个字符串比另一个字符串长，就将多出来的字母追加到合并后字符串的末尾。

返回合并后的字符串。

提示：

1 <= word1.length, word2.length <= 100

word1和word2由小写英文字母组成

**我的尝试**

**第一种**

整体思路：

1. 新建数组

2. 通过循环反复切片

3. 可行性：不存在区域的切片不会报错；题目给出len最长为100

```python
class Solution(object):
    def mergeAlternately(self, word1, word2):
        """
        :type word1: str
        :type word2: str
        :rtype: str
        """
        # 我打算使用邪修
        # 使用[:]来回切割，持续100次，看我操作
        ans = ""
        for i in range(100):
            ans += word1[i:i+1]
            ans += word2[i:i+1]
        return ans
```

运行时间：3ms

::: warning
以上解法十分暴力、丑陋，需要题目的“配合”
:::

**第二种**

整体思路：

1. 将字符串转化为列表

2. 通过列表的方法设定每一个字母的位置

3. 将列表转化为字符串输出

```python
class Solution(object):
    def mergeAlternately(self, word1, word2):
        """
        :type word1: str
        :type word2: str
        :rtype: str
        """
        lst1 = list(word1)
        lst2 = list(word2)
        final_lst = [] * (len(lst1) + len(lst2)) * 2

        for i in range(len(lst1)):
            final_lst[2*i] = lst1[i]
        for j in range(len(lst2)):
            final_lst[2*j+1] = lst2[j]
        ans = ''.join(final_lst)
        return ans
```

::: tip
`None*index`格式初始化列表长度，为后面直接调用做准备

不存在`2i`的写法，要写成`2*i`

列表转化为字符串要用`''.join(lst)`
:::

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        for i in range(1, n // 2 + 1):
            if n % i == 0:
                if all(s[j] == s[j - i] for j in range(i, n)):
                    return True
        return False
```

这里n是长度

### 13. 罗马数字转整数

罗马数字包含以下七种字符: I， V， X， L，C，D 和 M。

字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000

例如， 罗马数字 2 写做 II ，即为两个并列的 1 。12 写做 XII ，即为 X + II 。 27 写做  XXVII, 即为 XX + V + II 。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 IIII，而是 IV。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4 。同样地，数字 9 表示为 IX。这个特殊的规则只适用于以下六种情况：

I 可以放在 V (5) 和 X (10) 的左边，来表示 4 和 9。

X 可以放在 L (50) 和 C (100) 的左边，来表示 40 和 90。 

C 可以放在 D (500) 和 M (1000) 的左边，来表示 400 和 900。

给定一个罗马数字，将其转换成整数。

提示：

1 <= s.length <= 15

s 仅含字符 ('I', 'V', 'X', 'L', 'C', 'D', 'M')

题目数据保证s是一个有效的罗马数字，且表示整数在范围[1, 3999]内

题目所给测试用例皆符合罗马数字书写规则，不会出现跨位等情况。

IL和IM这样的例子并不符合题目要求，49 应该写作 XLIX，999 应该写作 CMXCIX。

关于罗马数字的详尽书写规则，可以参考 罗马数字 - 百度百科。

**我的尝试**

```python
class Solution(object):
    def romanToInt(self, s):
        """
        :type s: str
        :rtype: int
        """
        #肯定是先判断大小决定是否是特殊情况
        a = ['I', 'V', 'X', 'L', 'C', 'D', 'M']
        d = [1,5,10,50,100,500,1000]
        b = len(s)
        c = [1] * b
        num = 0
        for i in range(b):
            if i == b-1:
                break
            if a.index(s[i]) < a.index(s[i+1]):
                c[i] = -1
        for j in range(b):
            num += c[j] * d[a.index(s[j])]
        return num
```

运行时间：27ms

机器人按顺序执行指令instructions，并一直重复它们。

```python
class Solution(object):
    def isRobotBounded(self, instructions):
        """
        :type instructions: str
        :rtype: bool
        """
        left = instructions.count("L")
        right = instructions.count("R")
        go = instructions.count("G")
        if abs(left-right)==0 and go != 0:
            return False
        if go == 0:
            return True
        #判断要过多少次才能方向一致
        i = 1
        while True:
            if (4*i)%(abs(left-right))==0:
                times = (4*i)//abs(left-right)
                break
            i += 1
        #再次到达方向一致的情况，看是否到达原点，现在开始遍历
        dire = 1j
        pos = 0+0j
        for a in range(times):
            for b in range(len(instructions)):
                if instructions[b] == "L":
                    dire *= 1j
                elif instructions[b] == "R":
                    dire *= -1j
                else:
                    pos += dire
        if pos == 0+0j:
            return True
        else:
            return False
```

### 1672. 最富有客户的资产总量

给你一个m*n的整数网格accounts，其中accounts[i][j]是第i​​​​​​​​​​位客户在第j家银行托管的资产数量。返回最富有客户所拥有的资产总量。

客户的资产总量就是他们在各家银行托管的资产数量之和。最富有客户就是资产总量最大的客户。

**我的尝试**

```python
class Solution(object):
    def maximumWealth(self, accounts):
        """
        :type accounts: List[List[int]]
        :rtype: int
        """
        m = len(accounts)
        n = len(accounts[0])
        max_num = 0
        for i in range(m):
            num = 0
            for j in range(n):
                num += accounts[i][j]
            if max_num < num:
                max_num = num
        return max_num
```

### 1572. 矩阵对角线元素的和

给你一个正方形矩阵mat，请你返回矩阵对角线元素的和。

请你返回在矩阵主对角线上的元素和副对角线上且不在主对角线上元素的和。

**我的尝试**

```python
class Solution(object):
    def diagonalSum(self, mat):
        """
        :type mat: List[List[int]]
        :rtype: int
        """
        num = 0
        for i in range(len(mat)):
            num += mat[i][i]
            mat[i][i] = 0
            num += mat[len(mat)-1-i][i]
            mat[len(mat)-1-i][i] = 0
        return num
```

### 54. 螺旋矩阵

给你一个m行n列的矩阵matrix，请按照顺时针螺旋顺序，返回矩阵中的所有元素。

**我的尝试**

```python
class Solution(object):
    def spiralOrder(self, matrix):
        """
        :type matrix: List[List[int]]
        :rtype: List[int]
        """
        key = [-1,0]
        ud = 1
        lr = 1
        ans = []
        m = len(matrix[0])
        n = len(matrix)
        num = n*m
        while num != 0:
            if ud*lr == 1: #横向
                for i in range(0,m,1):
                    key[0] += lr
                    ans.append(matrix[key[1]][key[0]])
                    num -= 1
                m -= 1
                n -= 1
                lr *= -1
            else: #纵向
                for i in range(0,n,1):
                    key[1] += ud
                    ans.append(matrix[key[1]][key[0]])
                    num -= 1
                ud *= -1
        return ans
```
