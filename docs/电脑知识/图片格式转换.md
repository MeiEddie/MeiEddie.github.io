# 图片格式转换

## 方法1：bat命令

此方法需要将待处理图片放入一个独立文件夹（防止操作影响其它图片）

1. 新建文件夹，放入待处理图片
2. 在该文件夹内部新建文本文档，文本输入`ren *待转化格式 *转化后格式`

> `.`和空格都不能省略

示例：`.webp`转`.png`

```
ren *.webp *.png
```

3. 保存后叉掉文本文档，将文件扩展名改为`.bat`

> 没有扩展名：点击上方栏的`查看`，勾选`文件扩展名`

4. 双击运行`.bat`文件，满足命令条件的文件便会被更改
5. 之后，便可以按照[打印PDF](#打印pdf)的步骤进行操作
