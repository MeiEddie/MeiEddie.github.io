# 图片转PDF

## 打印PDF

图片所需格式：`.png``.jpg`

**步骤**

1. 选中需要打印的图片（按住shift可以快速选中）

> 注意图片顺序需要正序排列（即从上到下，从左到右）

2. 右键第一张图片（最上最左），选择打印
3. 打印机选择`Microsoft Print to PDF`，右侧选择需要的格式，进行打印

> 预览图即为打印出的PDF样式，不存在二次旋转

4. 选择PDF的保存地址，点击确定，等待打印完成

## 其他格式的图片

例如`.webp`等格式图片无法右键打印，需要全部转格式后再进行操作

### bat命令

此方法需要将待处理图片放入一个独立文件夹（防止操作影响其它图片）

1. 新建文件夹，放入待处理图片
2. 在该文件夹内部新建文本文档，文本输入`ren *待转化格式 *转化后格式`

> `.`和空格都不能省略

示例：`.webp`转`.png`

```
ren *.webp *.png
```

3. 保存后叉掉文本文档，将文件扩展名改为`.bat`

> 没有扩展名：点击上方栏的`查看`，勾选`文件扩展名`

4. 双击运行`.bat`文件，满足命令条件的文件便会被更改
5. 之后，便可以按照[打印PDF](#打印pdf)的步骤进行操作
