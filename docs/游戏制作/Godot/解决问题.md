# 解决问题

## 遮挡

**错误节点搭配**

```
Node2D
├─CanvasLayer
│  ├─ColorRect
│  └─Sprite2D
├    └─Area2D
├      └─CollisionShape2D
└─CanvasLayer
```

::: tip
当有了ColorRect的时候，Area2D无法被判定，只有游戏启动时鼠标刚好放在碰撞区内才触发一次移入
:::

**正确节点搭配**

```
Node2D
├─CanvasLayer
│  ├─TextureRect （或者删除该节点）
│  └─Sprite2D
├    └─Area2D
├      └─CollisionShape2D
└─CanvasLayer
```
