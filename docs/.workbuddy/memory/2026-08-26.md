# 2026-08-26 工作日志

## 修复博客头像与 PDF 线上 404 问题（VitePress + GitHub Pages）

### 背景
- 头像本地预览正常，托管 GitHub Pages 后不显示
- "理论学习/python/我的资源"页 PDF 跳转 404

### 根因（本地构建产物验证）
VitePress 构建时**不会自动复制 docs/ 下的静态文件进 dist**，以下情况会 404：
1. hero 头像 `./avatar.jpg`（hero image 是字符串，不触发资源复制）
2. PDF 普通链接 `[text](path.pdf)`（非图片语法，不复制）
3. `/assets/...` 绝对路径引用（按 public 目录处理，但无 public 目录）

### 修复
1. `.github/workflows/deploy.yml`：Build 后新增复制步骤，把 `docs/avatar.jpg` 和 `docs/assets/` 复制进 `docs/.vitepress/dist/`
2. `docs/理论学习/python/我的资源.md`：`知识总结1` 链接补 `.pdf` 扩展名
3. 更新 `docs/更改报告.txt`

### 经验（重要）
- VitePress 中保证资源线上可用：放 `docs/public/` 或用图片语法相对引用；否则需在 CI 构建后手动复制
- hero image src 建议用 public 路径 `/xxx.jpg` 或 CI 复制
- base: "/" 正确（bundle 绝对路径正常加载 → 根路径部署）
