# 消防安全（实践）

课程时间：2026.8.23 14:30~16:00

课程地点：中山大学英东体育场

## 活动内容

1. 讲解防烟面罩的使用

正式名称：过滤式消防自救呼吸器

打开塑料盒子，面罩在真空包装袋中，撕开包装袋取出面罩

嘴部的两面都有橡皮塞，拔开橡皮塞（两面都拔），之后套到头上，系紧带子

> 头发长要全部塞进面罩之中，防止烟尘进入面罩

2. 讲解灭火器的使用（干粉灭火器）
3. 灭火水枪的使用
4. 充气式消防逃生体验屋

介绍：

整体是充气气模，内部有充气隔断，造出弯弯绕绕迷宫式通道，有独立入口、出口

搭配安全无毒的演练发烟机，放出白色模拟浓烟，内部变暗，有的还加火灾警报音效，模拟火场充满烟雾的楼道环境

体验者进去必须弯腰低姿、捂口鼻，沿着疏散指示标志摸索找到出口

现场情况：

并没有模拟浓烟，也无指示标志，同学多，有点像走迷宫

5. 消防人员的工具介绍

无齿锯：高速切割钢筋、混凝土、铁门

机动链锯：切割木头

太平斧、撬棍：劈门撬锁
