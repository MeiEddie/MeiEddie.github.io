# Excel表格滚动条过短，一拖就飞出去

## 产生问题的可能原因

当我们不小心对太过边缘的位置进行了操作之后，Excel表有时会残留格式、边框、复制痕迹

例如缩放的过程就可能产生格式残留

此时，Excel把它们当成“已经使用的区域”，所以把滚动范围扩展到很靠边缘，这就导致了我们在滑动滚动条的时候精度过低，不方便操作

## 快捷操作

选中`列`，按下`Ctrl`+`Shift`+`→`键，可以一键选中该列右侧所有的区域（包含该列）

```
此时，右侧所有的内容、格式等等都会被清除

但是行列的填充色不会消失
```

同理，选中`行`，按下`Ctrl`+`Shift`+`↓`键，可以一键选中该行下方所有的区域（包含该行）

此方法也可用于快速删除不需要的部分，上下左右键可自己决定

例如：选中某个格子，按下`Ctrl`+`Shift`+`→`+`↓`键，可以一键选中该格子右下方的矩形区域（包含该格子）
