# 前端部分（简要介绍）

进一步了解可以参考 [理论学习](../../理论学习/简介){target=blank} 中的`前端`部分

## 前端

Front‑end，客户端

用户可以直接看到、交互的一切，所见即所得

## 前端三大件：HTML、CSS、JavaScript

### 1. HTML是网页的骨架

**HyperText Markup Language 超文本标记语言**

- 作用：搭网页结构，定义页面上有什么东西：标题、段落、按钮、图片、表格、输入框。
- 只负责“有什么”，**不管长什么样，不管动作**。
- 示例：

```html
<h1>标题</h1> <p>一段文字</p> <img src="a.jpg"> <button>按钮</button>
```

### 2. CSS是网页的样式

**Cascading Style Sheets 层叠样式表**

- 作用：控制外观：颜色、字体大小、间距、背景、布局、圆角、动画、排版。
- 管理网页的外观和布局，而不是实现点击交互等逻辑。
- 示例：设置字体红色，容器宽度，居中，阴影。

```css
h1 { color: red; font-size:24px; }
```

### 3. JavaScript(JS)是网页的行为交互

- 作用：实现动态逻辑、交互。点击按钮、弹窗、表单校验、数据计算、网络请求、修改页面内容。
- HTML是结构，CSS是样子，**JS负责“做事情”**。
- 示例：点击按钮弹出提示；表格增加一行；向后端请求数据渲染列表。

```javascript
alert('你好');
button.onclick = ()=>{ console.log('按钮被点击') }
```

> 三者协作关系：
> HTML搭骨架 → CSS美化 → JS负责交互干活。
> 只有HTML+CSS的网页是静态页面，不能响应用户操作；加上JS才是动态网页。
