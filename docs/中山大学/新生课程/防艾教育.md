# 防艾教育

课程时间：2026.8.21 15:30~16:30

主讲：黄湛镰

## 传染病特点

1. 病原体引起疾病
2. 人与人传播、人与动物传播

### 传播途径

呼吸道传播、消化道传播、血液体液传播、虫媒传播

## 艾滋病

全称获得性免疫缺陷综合征，由人类免疫缺陷病毒（HIV）感染引起的慢性乙类传染病。

HIV专门破坏人体CD4+免疫淋巴细胞，慢慢摧毁免疫系统，后期会发生各种严重感染、肿瘤；目前无法彻底根治，但规范治疗可以接近正常人寿命。

### 三大传播途径

1. 性接触传播：无保护的同性、异性性行为，肛交风险更高
2. 血液传播：共用吸毒针具；输入污染血液；消毒不到位的纹身、穿刺等
3. 母婴传播：感染HIV的妈妈怀孕、分娩、哺乳传给宝宝
