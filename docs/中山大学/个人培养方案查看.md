# 化学学院化学类专业培养方案

本科培养方案

年级：2026

学院：化学学院

专业：化学类

化学学院26级化学类大类主修培养方案

## 一、培养目标

本专业坚持社会主义办学方向，全面落实立德树人根本任务，聚焦培养能够引领未来的人，坚持以学生成长为中心，坚持通识教育与专业教育相结合，着力提升学生的学习力、思想力、行动力，培养德智体美劳全面发展的社会主义建设者和接班人。同时，注重基础理论教育与应用实践教育的有机结合，着力提升学生的创新能力、实践能力和解决复杂实际问题的分析能力，培养具有良好科学素养和社会责任心的高素质、宽口径化学人才，使学生能够适应新质生产力发展需求，适宜在化学、应用化学及相关学科攻读研究生，或者在化学及相关行业从事研究、开发、教育及管理等工作。

## 二、毕业要求

### （1）知识层面：

1. 掌握数学、物理等相关学科基本内容，夯实化学专业认知基础，了解化学的发展历史、学科前沿和发展趋势。
2. 系统、扎实地掌握化学专业的基础理论。
3. 系统、扎实地掌握化学专业的基本实验方法及技能。
4. 掌握化学工程、生命科学、材料科学、能源科学等相关交叉学科的基本知识。
### （2）能力层面：

5. 拥有良好的思想素质、身体素质、军事素养、劳动素质。
6. 具备一定的英语听说读写能力，能够顺利使用英语进行学术交流、阅读和写作。
7. 能熟练运用化学专业的基础理论知识分析问题，设计解决方案。
8. 能熟练运用化学专业的基本实验方法及技能解决问题。
9. 初步具备自主学习、自我发展的能力，具备宽阔的专业视野和专业素养，成为高素质、宽口径的复合型化学人才。
### （3）价值层面：

10. 具有健全的心理素质、健康的体魄和良好的学术修养，拥有正确的世界观、人生观和价值观。
11. 具备良好的团队协作精神和集体荣誉感。
12. 拥有正确的国家安全意识，具备浓烈的爱国情怀，树立报效国家的远大理想和志向。

## 三、授予学位与修业年限

按要求完成学业者授予理学学士学位。修业年限：4年。

备注：

```
学生可根据自身兴趣及未来规划选择制定专业选修课的学习计划，但需满足以下要求：
1.达到毕业要求且“化学方向课”模块修满12学分及以上的学生，授予理学学士学位，毕业专业为化学（070301）；
2.达到毕业要求且“应用化学方向课”模块修满12学分及以上的学生，授予理学学士学位，毕业专业为应用化学（070302）；
```
