## 层级编码/杜威十进分类法（DDC）

发明人：梅尔维尔・杜威（Melvil Dewey），图书馆用的经典分类系统

**示例**

```
100 哲学与心理学（大类）
110 形而上学（100下面子类）
120 认识论
130 超心理学
……
200 宗教（另一个大类）
```

### 使用场景

**GB/T 2260行政区划代码（身份证前6位）**

`44`广东——`4401`广州——`440105`海珠区，高位代表上级，低位代表下级

**可能的误会**

我国特服电话（110、120、119）不采用杜威十进分类法

`11×`：紧急报警类号段；`12×`：公益服务；`123XX`政务热线

历史原因：老式转盘电话，`11`开头拨号步数少，优先分配给紧急业务，追求好记、拨号快，不是做层级分类
