# 图片转PDF

## 打印PDF

图片所需格式：`.png``.jpg`

**步骤**

1. 选中需要打印的图片（按住shift可以快速选中）

> 注意图片顺序需要正序排列（即从上到下，从左到右）

2. 右键第一张图片（最上最左），选择打印
3. 打印机选择`Microsoft Print to PDF`，右侧选择需要的格式，进行打印

> 预览图即为打印出的PDF样式，不存在二次旋转

4. 选择PDF的保存地址，点击确定，等待打印完成

## 其他格式的图片

例如`.webp`等格式图片无法右键打印，需要全部转格式（`.png`或`.jpg`）后再进行操作

图片格式转换方法可以参考 [图片格式转换](图片格式转换){target=blank} 。
