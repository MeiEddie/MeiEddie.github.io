## 评价指标

### 时间复杂度

简单来说，有关数据规模n变大时，算法执行次数增长的趋势

n：输入数据规模（数组长度、循环次数）

大O表示法：只看`最高次项`，忽略常数、低次项

**示例**

```
执行次数公式T(n)=3n2+5n+100

当n极大时，5n+100完全可以忽略，常数3也丢掉

最终时间复杂度：O(n2)
```

##### 计算时间复杂度

1. 常数直接记作O(1)

不管循环多少次，只要和n无关：

T(1000)→O(1)

2. 只保留最高次方项

T(n)=n3+10n2→O(n3)

3. 去掉最高项前面的系数

T(n)=5n2→O(n2)

##### 时间复杂度比较

O(1) < O(logn) < O(n) < O(nlogn) < O(n2) < O(n3) < O(2n) < O(n!)

::: tip
O(nlogn)线性对数，是排序算法核心。数据量大的时候远远快于O(n2)
:::

##### 问题

为什么工程优先使用快速排序？

> 虽然快排最坏是O(n2)，但是随机数据下几乎碰不到最坏情况，并且O(nlogn)里常数最小，实际速度最快。

### 空间复杂度

衡量算法运行时，额外开辟的内存空间随输入规模n的增长趋势。

不算原始输入数据占用的内存，只统计：临时变量、数组、链表、递归调用栈等新增内存

### 稳定性

稳定排序：如果两个元素的值相等，排序之后，它们在原数组中的先后顺序保持不变。

不稳定排序：值相等的元素，排序后相对位置可能颠倒。

> 不稳定排序不是一定会颠倒，只是存在颠倒的可能性。

在多关键字排序的时候，可以先按照次要条件排序，然后使用稳定排序排列主要条件

## 基础算法

### 冒泡排序（Bubble Sort）

<br>

##### 逻辑+代码实现

逻辑：相邻两个比较，大的往后交换，每一轮把最大值“浮”到末尾

特点：最简单，效率低，稳定排序

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr
```

我们可以通过检测交换进一步减少运行的步骤

```python
def bubble_sort(arr):
   n = len(arr)
   for i in range(n - 1):
       swapped = False # 标记本轮是否发生交换
       for j in range(n - 1 - i):
           if arr[j] > arr[j + 1]:
               arr[j], arr[j + 1] = arr[j + 1], arr[j]
               swapped = True
       if not swapped: # 若无交换，提前结束
           break
   return arr
```

::: tip
外层循环控制轮数，每轮将最大值放到末尾。

内层循环比较相邻元素并交换。

swapped标志位可在数组已排序时提前结束，提升效率。
:::

### 选择排序（Selection Sort）

<br>

##### 逻辑+代码实现

逻辑：每一轮找到最小值，放到当前最前面

特点：交换次数少，不稳定排序

```python
def select_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

##### 时间复杂度

选择排序的时间复杂度为`O(n²)`，因为它需要进行两层嵌套循环来找到最小值并进行交换。

虽然选择排序的实现简单，但由于其时间复杂度较高，适用于数据规模较小的情况。

## 内置函数

用来提高工作、刷题效率

### Python内置排序

底层是Timsort（归并+插入混合排序），是稳定排序

```python
lst = [3,1,4,2]

# 1.原地排序，修改原列表
lst.sort()

# 2.返回新列表，原数据不变
new_lst = sorted(lst)
```

> 优点：稳定、速度快、支持自定义规则sorted(lst, key=..., reverse=...)
