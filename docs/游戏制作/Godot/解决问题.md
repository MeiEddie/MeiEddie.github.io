# 解决问题

## 遮挡

**错误节点搭配**

```
Node2D
├─CanvasLayer
│  ├─ColorRect
│  └─Sprite2D
├    └─Area2D
├      └─CollisionShape2D
└─CanvasLayer
```

::: tip
当有了ColorRect的时候，Area2D无法被判定，只有游戏启动时鼠标刚好放在碰撞区内才触发一次移入
:::

**正确节点搭配**

```
Node2D
├─CanvasLayer
│  ├─TextureRect （或者删除该节点）
│  └─Sprite2D
├    └─Area2D
├      └─CollisionShape2D
└─CanvasLayer
```

## Button节点

Button节点没有visible属性，可以使用`.show()`和`.hide()`进行显示和隐藏

除此之外，可以使用`modulate`属性进行显示和隐藏，配套使用`disabled`属性防止误触
