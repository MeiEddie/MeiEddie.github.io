# 网络协议

网络协议是网络设备之间通信的一套共同约定（规则、格式、时序），可以让不同厂商、不同系统的设备能看懂互相发送的数据

## HTTP/HTTPS

客户端与服务器之间的通信协议

### HTTP状态码

- 2xx 成功
  - 200 OK：查询成功
  - 201 Created：POST创建资源成功
- 3xx 重定向
- 4xx 客户端错误
  - 400 Bad Request：参数格式错误
  - 401 Unauthorized：未认证，缺少token/token失效
  - 403 Forbidden：认证成功，但没有权限访问
  - 404 Not Found：接口地址不存在
  - 405 Method Not Allowed：接口不支持这个请求方法，例如接口只支持GET
- 5xx 服务端错误
  - 500 Internal Server Error：服务内部异常
  - 503 Service Unavailable：服务不可用、宕机

## WebSocket

实现客户端与服务器的双向实时通信（如聊天应用）
